Wazuh SIEM Lab Notes: Deploying a Manager, Agents, and a First Detection Rule

Lab notes from building a Wazuh environment on a test network. These notes cover the setup steps and one example rule. They describe a lab, not a production deployment.

Components

  • Wazuh manager: receives agent events and runs detection rules.
  • Wazuh agents: installed on test endpoints to forward logs and events.
  • Wazuh indexer and dashboard: store events and provide search and visualization.

Lab setup

I ran the stack on a single Ubuntu VM with Docker Compose, then enrolled two test endpoints as agents. Check the official Wazuh Docker deployment guide for the current image tags and environment variables before reusing any configuration.

Example detection rule

This rule raises an alert after repeated failed SSH logins from the same source IP. Treat it as a starting point and test it against your own log samples.

<rule id="100100" level="10">
  <if_matched_sid>5716</if_matched_sid>
  <same_source_ip />
  <frequency>5</frequency>
  <timeframe>300</timeframe>
  <description>Repeated SSH authentication failures from one source IP</description>
  <mitre>
    <id>T1110</id>
  </mitre>
</rule>

Rule ID 5716 refers to Wazuh's built-in SSH failed-login rule. Confirm the ID in your version's rule set.
